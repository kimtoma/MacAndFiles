# MacAndFiles production icon

The selected production artwork is the original **08: Android Courier** concept: a green full-body Android mascot holding an ivory document with blue opposing transfer arrows, on a cornflower-blue rounded-square tile. The master is AppIcon-master.png, a 1254×1254 RGBA PNG. The folder-holding 08-B and white-background 08-C remain alternatives only.

## Rebuild

Run scripts/build-icon.sh from the repository root. scripts/make-icon.swift uses AppKit to produce ten standard 16–1024px ICNS representations, preserving the original alpha. No image-generation account, API key or remote service is needed to build. Preview.png compares small sizes on light/dark backgrounds.

## Final generation prompt

Create a single exquisite original app icon for Android Bridge, a native macOS utility exchanging files with Android. Use the recognizable green Android robot mascot: simple dome head, two short angled antennae, two black circular eyes, optional cylindrical torso and small arms. Freedom to redesign layout, NOT a folder-based icon. NO folder anywhere, NO phones, screens, computers, cables, text, letters, watermark or mockup. One rounded-square macOS icon tile occupying 88% of square canvas, equal transparent outer margins. Intentional bold silhouette and beautiful clear negative space, simplified forms that read at 32px, exceptional designer-crafted finish. The visual communicates file exchange using files or two opposing arrows. Green is used for the Android mascot; blues and ivory complement it. Style: delightful high-quality sculpted matte clay / soft ceramic illustration, generous rounded shapes, subtle ambient contact shadows, no glossy plastic and no metal. Rich deep cornflower-blue tile. Composition: a cute recognizable full-body green Android robot standing centrally, its head intentionally large, hugging a single large ivory document file diagonally against its chest with one small rounded arm; document has a folded corner and a small embossed blue two-opposing-arrows symbol. The other arm reaches outward as if handing over the file. Strong mascot-led composition with no extra sheets, no background scenery. Beautiful friendly character silhouette, satin surfaces, face has two round black eyes only, no mouth. The document and bot form a single compact emblem.
