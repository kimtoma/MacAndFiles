MacAndFiles

在 Mac 上，轻松管理 Android 文件。

下载 Mac 版 ↓GitHub ↗

开发版本 · 免费开源

融入你的 Mac。

Finder 风格浏览器、原生搜索和系统配色。拖入文件，浏览文件夹，保存所需内容。

了解传输进度。

查看总文件数、完成数、总体进度、平均速度与预计剩余时间。传输停止时保留已完成文件。

也可使用终端。

maf CLI 使用相同传输引擎，提供 JSON 结果、稳定错误代码与清晰的 USB 会话状态。

在应用的更多 → 终端和智能体中安装 maf。按需将 ~/.local/bin 加入 PATH。CLI 文件操作前请断开 GUI 连接。

连接，选择，传输。

  1. 使用 USB 数据线连接，解锁 Android 并选择文件传输 / Android Auto。
  2. 退出其他 MTP 应用，在 MacAndFiles 中选择设备并连接。
  3. 选择发送到 Android 或保存到 Mac。文件夹递归复制，不会静默覆盖同名文件。

实用说明。

搜索会扫描整个设备吗？

搜索只筛选当前文件夹中的文件名，不扫描整个设备或应用专用存储。

文件会经过云服务吗？

不会。通过 USB 本地传输。应用及本网站无需账户，无云端中转、分析追踪或广告。

透明的开发版本。

Apple Silicon · macOS 14 或更高. 面向 macOS 14+ 构建，已在 macOS 27.2 验证；旧版本仍需实机验证。macOS 26+ 支持 Liquid Glass。

下载的 ZIP 是 ad-hoc 签名开发版本，尚未完成 Developer ID 签名及 Apple 公证。可本地构建；发布状态记录在仓库中。
