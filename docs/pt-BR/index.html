Versão de desenvolvimento · Grátis e de código aberto

Em casa no Mac.

Navegador estilo Finder, busca nativa e cores do sistema. Arraste arquivos, explore pastas e salve o necessário.

Acompanhe o que se move.

Veja arquivos totais e concluídos, progresso geral, velocidade média e tempo restante estimado. Arquivos concluídos são preservados se a transferência parar.

Também no terminal.

maf compartilha o motor de transferência: resultados JSON, erros estáveis e estado USB claro para scripts e agentes.

Instale maf em Mais → Terminal e agentes. Se necessário, adicione ~/.local/bin ao PATH. Desconecte a GUI antes de operar pela CLI.

Conecte. Escolha. Transfira.

  1. Conecte um cabo USB de dados. Desbloqueie Android e selecione Transferência de arquivos / Android Auto.
  2. Feche outros apps MTP. No MacAndFiles, selecione o dispositivo e conecte.
  3. Envie ao Android ou salve no Mac. Pastas são copiadas recursivamente e nomes existentes nunca são sobrescritos silenciosamente.

Detalhes úteis.

A busca percorre todo o dispositivo?

Filtra nomes na pasta atual, sem varrer todo o dispositivo ou dados privados de apps.

Os arquivos passam pela nuvem?

Não. Transferência local via USB. O app e o site não têm conta, retransmissão na nuvem, análise de uso ou anúncios.

Desenvolvimento transparente.

Apple Silicon · macOS 14 ou posterior. Compilado para macOS 14+. Testado no macOS 27.2; versões anteriores ainda precisam de testes reais. Liquid Glass no macOS 26+.

O ZIP é uma versão de desenvolvimento com assinatura ad-hoc. Developer ID e notarização Apple ainda não foram concluídos. Você pode compilar localmente; o repositório registra o estado.
