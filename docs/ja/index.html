MacAndFiles

Androidのファイルを、使い慣れたMacで。

Mac版をダウンロード ↓GitHub ↗

開発版 · 無料・オープンソース

Mac に自然になじむ。

Finder 風ブラウザ、ネイティブ検索、システムカラー。ドラッグして、フォルダを開き、必要なものを保存。

転送状況を見渡す。

総ファイル数、完了数、全体の進捗、平均速度、残り時間の目安を表示。停止しても完了したファイルは保持されます。

ターミナルでも。

maf は同じ転送エンジンを使い、JSON 結果、安定したエラーコード、USB セッション状態を提供します。

その他 → ターミナルとエージェントから maf をインストール。必要なら ~/.local/bin を PATH に追加。CLI 操作前に GUI 接続を切断してください。

つないで、選んで、転送。

  1. USB データケーブルで接続し、Android のロックを解除してファイル転送 / Android Auto を選択。
  2. ほかの MTP アプリを終了し、MacAndFiles でデバイスを選んで接続。
  3. Android に送信、または Mac に保存。フォルダを再帰コピーし、同名のファイルを黙って上書きしません。

知っておきたいこと。

検索はデバイス全体を探しますか？

現在のフォルダのファイル名を絞り込みます。デバイス全体やアプリ専用領域は検索しません。

ファイルはクラウドを経由しますか？

いいえ。USB でローカル転送します。アプリとサイトにアカウント、クラウド中継、分析追跡、広告はありません。

開発版の状態を明確に。

Apple Silicon · macOS 14 以降. macOS 14+ 向けにビルド。macOS 27.2 で検証済み。旧バージョンの実機検証は未実施です。Liquid Glass は macOS 26+。

ZIP は ad-hoc 署名の開発版です。Developer ID 署名と Apple 公証は未完了です。ローカルビルドもでき、状態はリポジトリに記録します。
