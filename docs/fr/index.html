Chez elle sur votre Mac.

Explorateur façon Finder, recherche native et couleurs système. Déposez des fichiers, parcourez les dossiers et enregistrez le nécessaire.

Suivez le transfert.

Nombre total, fichiers terminés, progression globale, vitesse moyenne et temps restant estimé. Les fichiers terminés restent conservés en cas d’arrêt.

Aussi dans le terminal.

maf partage le moteur de transfert : résultats JSON, erreurs stables et état USB clair pour scripts et agents.

Installez maf via Plus → Terminal et agents. Ajoutez ~/.local/bin au PATH si nécessaire. Déconnectez la GUI avant une opération CLI.

Connectez. Choisissez. Transférez.

  1. Branchez un câble USB de données, déverrouillez Android et choisissez Transfert de fichiers / Android Auto.
  2. Fermez les autres apps MTP. Dans MacAndFiles, sélectionnez l’appareil et connectez-le.
  3. Envoyez vers Android ou enregistrez sur Mac. Copie récursive des dossiers, sans écrasement silencieux.

Quelques précisions.

La recherche parcourt-elle tout l’appareil ?

Elle filtre les noms dans le dossier actuel, sans parcourir tout l’appareil ni les données privées des apps.

Les fichiers passent-ils par le cloud ?

Non. Transfert local via USB. App et site sans compte, relais cloud, analyse d’usage ni publicité.

Un développement transparent.

Apple Silicon · macOS 14 ou ultérieur. Compilée pour macOS 14+. Testée sur macOS 27.2 ; les versions antérieures restent à vérifier sur matériel réel. Liquid Glass dès macOS 26.

Le ZIP est une version de développement signée ad-hoc. Signature Developer ID et notarisation Apple ne sont pas terminées. Compilation locale possible ; état documenté dans le dépôt.
