A familiar place for your files.

Browse folders, search file names, and drag files in. Built with native Mac controls, system colors, and Liquid Glass on supported versions.

Every file accounted for.

File counts, overall progress, speed, and time remaining stay in view. If a transfer stops, completed files are preserved and the failed item is reported.

The same app. A short command.

The maf CLI shares the same transfer engine. JSON results, stable error codes and a clear USB session status help scripts and agents work reliably.

Install maf from More → Terminal and Agents in the app. If needed, add ~/.local/bin to PATH. Disconnect the GUI before a CLI file operation.

A cable is all you need.

  1. Connect with a USB data cable. Unlock Android and select File Transfer / Android Auto.
  2. Quit other MTP apps. Open MacAndFiles, select your device and connect.
  3. Send to Android or Save to Mac. Folders copy recursively; existing names are never silently overwritten.

Before you connect.

Does search look through the whole device?

Search filters file names in the current folder. It does not scan the entire device or app-private storage.

Do my files go through a cloud service?

No. Transfers run locally over USB. There is no account, cloud relay, analytics or advertising in the app or this site.

Release notes

Apple Silicon · macOS 14 or later. Built for macOS 14+. Tested on macOS 27.2; older versions still need real-device validation. Liquid Glass is available on macOS 26+.

The downloadable ZIP is an ad-hoc signed development build. Developer ID signing and Apple notarization are not yet complete. Build locally if you prefer; release status is documented in the repository.
