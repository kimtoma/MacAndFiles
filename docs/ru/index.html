Версия для разработки · Бесплатно и с открытым кодом

Как дома на Mac.

Браузер в стиле Finder, нативный поиск и системные цвета. Перетаскивайте файлы, открывайте папки и сохраняйте нужное.

Передача под контролем.

Всего и завершено файлов, общий прогресс, средняя скорость и оценка оставшегося времени. При остановке завершённые файлы сохраняются.

Есть и терминал.

maf использует тот же движок: JSON, стабильные коды ошибок и понятный статус USB для скриптов и агентов.

Установите maf через Ещё → Терминал и агенты. При необходимости добавьте ~/.local/bin в PATH. Перед CLI-операциями отключите GUI.

Руководство ↗
maf · CLI
maf devices
maf status
maf help

Подключите. Выберите. Передайте.

  1. Подключите USB-кабель данных, разблокируйте Android и выберите Передача файлов / Android Auto.
  2. Закройте другие MTP-приложения. В MacAndFiles выберите устройство и подключитесь.
  3. Отправляйте на Android или сохраняйте на Mac. Папки копируются рекурсивно, существующие имена не перезаписываются молча.

Полезные подробности.

Поиск охватывает всё устройство?

Он фильтрует имена в текущей папке, не сканируя всё устройство или закрытые данные приложений.

Файлы проходят через облако?

Нет. Локальная передача по USB. В приложении и на сайте нет учётных записей, облачного посредника, аналитики или рекламы.

Прозрачный статус разработки.

Apple Silicon · macOS 14 и новее. Сборка для macOS 14+. Проверено на macOS 27.2; старые версии ещё требуют проверки на устройствах. Liquid Glass с macOS 26.

ZIP — сборка для разработки с подписью ad-hoc. Подпись Developer ID и нотарификация Apple ещё не выполнены. Можно собрать локально; статус указан в репозитории.
