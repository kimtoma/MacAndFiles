MacAndFiles

Android 파일을 Mac에서 익숙하게.

Mac용 다운로드 ↓GitHub ↗

개발 버전 · 무료 오픈소스

Mac에 자연스럽게.

Finder 스타일 탐색기, 네이티브 검색과 시스템 컬러. 파일을 끌어 넣고 폴더를 탐색하며 필요한 파일을 저장하세요.

전송 상태를 한눈에.

전체·완료 파일 수, 전체 진행률, 평균 속도와 예상 남은 시간을 확인하세요. 전송이 중단되어도 완료된 파일은 보존됩니다.

터미널에서도.

maf CLI는 같은 전송 엔진을 사용합니다. JSON 결과, 안정적인 오류 코드와 USB 점유 상태로 스크립트와 에이전트의 작업을 돕습니다.

앱의 더 보기 → 터미널 및 에이전트에서 maf를 설치하세요. 필요한 경우 ~/.local/bin을 PATH에 추가하세요. CLI 파일 작업 전에는 GUI 연결을 해제하세요.

사용 안내 ↗
maf · CLI
maf devices
maf status
maf help

연결하고, 선택하고, 전송하세요.

  1. USB 데이터 케이블로 연결하고 Android 잠금을 해제한 뒤 파일 전송 / Android Auto를 선택하세요.
  2. 다른 MTP 앱을 종료하세요. MacAndFiles에서 기기를 선택하고 연결하세요.
  3. Android로 보내기 또는 Mac으로 저장을 선택하세요. 폴더는 재귀 복사하며 같은 이름을 조용히 덮어쓰지 않습니다.

알아두면 좋은 내용.

검색은 기기 전체를 탐색하나요?

검색은 현재 폴더의 파일명만 필터링합니다. 기기 전체나 앱 전용 저장소를 스캔하지 않습니다.

파일이 클라우드를 거치나요?

아니요. USB로 로컬 전송합니다. 앱과 사이트에 계정, 클라우드 중계, 분석 추적 또는 광고가 없습니다.

개발 배포 상태를 투명하게.

Apple Silicon · macOS 14 이상. macOS 14 이상을 대상으로 빌드했습니다. macOS 27.2에서 검증했으며 이전 버전의 실기기 검증은 남아 있습니다. Liquid Glass는 macOS 26 이상에서 적용됩니다.

다운로드 ZIP은 ad-hoc 서명된 개발 빌드입니다. Developer ID 서명과 Apple 공증은 아직 완료되지 않았습니다. 로컬 빌드도 가능하며 저장소에 배포 상태를 기록합니다.
