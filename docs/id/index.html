Versi pengembangan · Gratis & sumber terbuka

Serasi dengan Mac.

Browser bergaya Finder, pencarian native dan warna sistem. Seret file, jelajahi folder dan simpan yang diperlukan.

Pantau transfer.

Lihat total file, file selesai, kemajuan keseluruhan, kecepatan rata-rata dan perkiraan waktu tersisa. File selesai tetap aman saat transfer berhenti.

Juga di terminal.

maf memakai mesin yang sama: hasil JSON, kode kesalahan stabil dan status sesi USB yang jelas untuk skrip dan agen.

Pasang maf melalui Lainnya → Terminal dan agen. Tambahkan ~/.local/bin ke PATH bila perlu. Putuskan GUI sebelum operasi file CLI.

Hubungkan. Pilih. Transfer.

  1. Hubungkan kabel data USB, buka kunci Android dan pilih Transfer File / Android Auto.
  2. Tutup aplikasi MTP lain. Di MacAndFiles, pilih perangkat dan hubungkan.
  3. Kirim ke Android atau simpan ke Mac. Folder disalin rekursif; nama yang ada tidak ditimpa diam-diam.

Detail bermanfaat.

Apakah pencarian mencakup seluruh perangkat?

Pencarian memfilter nama di folder saat ini, bukan seluruh perangkat atau data privat aplikasi.

Apakah file melewati cloud?

Tidak. Transfer lokal melalui USB. Aplikasi dan situs tanpa akun, perantara cloud, analitik atau iklan.

Status pengembangan yang jelas.

Apple Silicon · macOS 14 atau lebih baru. Dibangun untuk macOS 14+. Diuji pada macOS 27.2; versi lama masih perlu validasi perangkat nyata. Liquid Glass di macOS 26+.

ZIP adalah versi pengembangan bertanda tangan ad-hoc. Developer ID dan notarisasi Apple belum selesai. Bisa dibangun lokal; status dicatat di repositori.
