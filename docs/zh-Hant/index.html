MacAndFiles

在 Mac 上，輕鬆管理 Android 檔案。

下載 Mac 版 ↓GitHub ↗

開發版本 · 免費開源

融入你的 Mac。

Finder 風格瀏覽器、原生搜尋與系統配色。拖入檔案，瀏覽檔案夾，儲存所需內容。

了解傳輸進度。

查看總檔案數、完成數、整體進度、平均速度與預估剩餘時間。傳輸停止時保留已完成檔案。

也能使用終端機。

maf CLI 使用相同傳輸引擎，提供 JSON 結果、穩定錯誤碼與清楚的 USB 工作階段狀態。

在應用程式的更多 → 終端機與代理中安裝 maf。按需將 ~/.local/bin 加入 PATH。CLI 檔案操作前請中斷 GUI 連線。

連接，選擇，傳輸。

  1. 使用 USB 資料線連接，解鎖 Android 並選擇檔案傳輸 / Android Auto。
  2. 結束其他 MTP 應用程式，在 MacAndFiles 中選擇裝置並連接。
  3. 選擇傳送到 Android 或儲存到 Mac。檔案夾遞迴複製，不會無聲覆寫同名檔案。

實用說明。

搜尋會掃描整個裝置嗎？

搜尋僅篩選目前檔案夾的檔案名稱，不掃描整個裝置或應用程式專用儲存空間。

檔案會經過雲端服務嗎？

不會。透過 USB 在本機傳輸。應用程式與網站無需帳號，無雲端中繼、分析追蹤或廣告。

透明的開發版本。

Apple Silicon · macOS 14 或以上. 以 macOS 14+ 為目標建置，已在 macOS 27.2 驗證；舊版本仍需實機驗證。macOS 26+ 支援 Liquid Glass。

下載的 ZIP 是 ad-hoc 簽署開發版本，尚未完成 Developer ID 簽署與 Apple 公證。可在本機建置；發布狀態記錄於儲存庫。
