MacAndFiles

ملفات Android، في بيئة Mac المألوفة.

تنزيل لنظام Mac ↓GitHub ↗

نسخة تطوير · مجانية ومفتوحة المصدر

ينسجم مع Mac.

متصفح على نمط Finder وبحث أصلي وألوان النظام. اسحب الملفات وتصفح المجلدات واحفظ ما تحتاج.

تابع النقل بوضوح.

عدد الملفات الكلي والمكتمل والتقدم العام ومتوسط السرعة والوقت المتبقي التقديري. تُحفظ الملفات المكتملة إذا توقف النقل.

وفي الطرفية أيضًا.

يستخدم maf محرك النقل نفسه: نتائج JSON ورموز أخطاء مستقرة وحالة USB واضحة للبرامج والوكلاء.

ثبّت maf من المزيد ← الطرفية والوكلاء. أضف ~/.local/bin إلى PATH عند الحاجة. افصل GUI قبل عمليات CLI.

الدليل ↗
maf · CLI
maf devices
maf status
maf help

اتصل. اختر. انقل.

  1. صل كابل بيانات USB وافتح قفل Android واختر نقل الملفات / Android Auto.
  2. أغلق تطبيقات MTP الأخرى. اختر الجهاز في MacAndFiles واتصل.
  3. أرسل إلى Android أو احفظ في Mac. تُنسخ المجلدات تكراريًا ولا تُستبدل الأسماء الموجودة بصمت.

تفاصيل مفيدة.

هل يبحث في الجهاز كله؟

يصفّي أسماء الملفات في المجلد الحالي فقط، دون مسح الجهاز كاملًا أو بيانات التطبيقات الخاصة.

هل تمر الملفات عبر السحابة؟

لا. نقل محلي عبر USB. لا حساب أو وسيط سحابي أو تحليلات أو إعلانات في التطبيق والموقع.

حالة تطوير واضحة.

Apple Silicon · macOS 14 أو أحدث. مُعدّ لـ macOS 14+ ومختبر على macOS 27.2؛ الإصدارات الأقدم تحتاج تحققًا فعليًا. Liquid Glass على macOS 26+.

ZIP نسخة تطوير موقعة ad-hoc. توقيع Developer ID وتوثيق Apple لم يكتملَا بعد. يمكن البناء محليًا؛ الحالة موثقة في المستودع.
