## Design Context

### Users

Mac users moving files and folders over USB to Android devices. The user started this project because the old Android File Transfer app would not launch, and designated Galaxy Z Fold7 as the actual test device. The project is intended to be shared as open source, with clear contributor instructions.

### Brand Personality

Native, minimal, approachable. Make file exchange clear and dependable. Use the user's selected original 08 Android Courier app icon; its friendly character belongs in app branding without turning the file browser into a decorative landing page.

### Aesthetic Direction

The user explicitly requested macOS Finder's default UI and system accent colors instead of a fixed green accent. Both macOS appearances should work with semantic system materials and system typography. The user asked to compare the locally built Android Transfer app and adopt useful ideas toward a more minimal interface. The appicons.store reference applies to icon craft and layout, not to turning the app UI into a gallery.

The user subsequently requested native macOS Liquid Glass. Use the system's glass sidebar and toolbar grouping, with glass for compact custom navigation controls. Keep the file table readable and use SwiftUI's native toolbar search instead of a decorated TextField.

### Design Principles

1. Files and folder navigation are the primary content. Use native macOS table, toolbar and sidebar conventions.
2. Show each device, path and state once. Move connection help and diagnostics to secondary entry points.
3. Keep transfer direction labels explicit (Android로 보내기 / Mac으로 저장); icon-only buttons retain accessible labels and tooltips.
4. Use system accent and semantic backgrounds; avoid decorative cards, marketing headings and repeated technical labels.
5. Preserve transfer safety, cancellation and visible errors while simplifying the UI. Keep the approved app icon unchanged.
