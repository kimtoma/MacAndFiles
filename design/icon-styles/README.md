# Android Bridge: graphic style exploration

Review concepts only, not installed or packaged. Generated with the built-in image generation tool. The PNGs retain their original generated alpha. Gallery.png uses opaque light backgrounds and dark Dock-sized previews for review. No production resources or installed app were changed.

## Art direction

User reference: https://www.appicons.store/
Observed qualities: prominent silhouettes, generous rounded-square spacing, a mix of bold outlined illustrations, simple flat symbols and sculpted 3D materials. These concepts were independently generated. No store artwork was downloaded or reused.

01-06 use the previous A-v2 concept as a conceptual reference, with materials and layouts reinterpreted. 03 was then distilled into a new geometric symbol. 07-09 respond to the user's expanded brief: Android mascot plus file exchange, without a required folder.

## Final prompts

### 01: Soft 3D

Use case: stylized-concept. Create a single polished app icon for Android Bridge, an independent native macOS file transfer utility. Input image is a CONCEPT reference ONLY: a blue open folder containing an Android character and ivory file documents, with opposing transfer arrows. Redesign the graphics completely according to the requested style rather than preserving its silver tile, geometry or lighting. Essential idea: a clearly OPEN file folder containing BOTH the recognizable Android robot (green dome head with two short angled antennae and two dark round eyes) and two file sheets. The lower portions of documents and bot are occluded by the front of the folder, visibly contained inside it. Include a modest pair of opposing arrows as a transfer motif on the folder front. No phones, screens, cables or computers. Strong instantly readable icon silhouette, high-end art direction, coherent geometry, intentional negative space, exceptionally well-crafted edges and balance. Square canvas, one macOS rounded-square icon tile occupying 88% of canvas, uniform outer transparent margins. No text, letters, labels, watermarks, borders, contact sheets or mockups. Android green confined to character, blue folder, ivory files. This is a distinct original icon, not a copy of another app icon.
Requested style and layout: Soft luminous 3D mascot style with inflated satin vinyl shapes, refined gradient lighting, delicate ambient occlusion, smooth broad forms and tiny sculpted highlights. Warm off-white rounded tile, NO silver rim. Layout: large central Android face above a compact rounded blue folder pocket, two ivory document tabs fanned slightly behind the left edge. Character face occupies the upper half, folder the lower half, a very small ivory opposing-arrow relief on folder front. Friendly and memorable but sophisticated, tactile designer toy quality. Restrained rich azure to indigo blue, clear fresh green.
